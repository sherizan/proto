# Native purchase layout fixture

Overlay these app routes and constants onto a disposable current scaffold. Keep its managed components, package versions and TouchDots wrapper. Open `/checkout/menu` for tabs, notes, scrolling and a review sheet; View details tests the native header and edge-swipe back. This fixture is hand-authored component evidence, not a model-quality benchmark.

Test ordinary and accessibility text, dark mode, keyboard clearance, final-content reachability and native dismissal on a compact phone and a larger phone. At font scales >= 1.8 or short viewports the purchase action scrolls with the content. Evidence from 2026-10-02 is in `docs/native-purchase-review.html` at the repository root.
