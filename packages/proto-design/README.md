# Shared Prototo design guidance

This directory is the canonical source for prototype design guidance and design profiles used by Prototo's scaffold, CLI/Desktop authoring and ChatGPT plugin. The guide is versioned separately from the native runtime. Explicit user branding and a project's existing design decisions take priority.

`SKILL.md` contains the shared design instructions. `manifest.json` records the guide version and supported runtime. `src/` contains the profile catalog, typography, configuration parser, contrast checks and generated design-note renderer. `fixtures/` contains isolated native layout, coffee artwork and loading examples.

From the repository root, synchronize after editing canonical sources:

```sh
pnpm design:sync
pnpm design:check
node scripts/sync-design-profiles.mjs --chatgpt ../prototo-chatgpt
node scripts/sync-design-guidance.mjs --chatgpt ../prototo-chatgpt
node scripts/sync-design-profiles.mjs --check --chatgpt ../prototo-chatgpt
node scripts/sync-design-guidance.mjs --check --chatgpt ../prototo-chatgpt
```

Generated copies are committed with their canonical sources. Template components are generated by create-proto's existing sync step. The ChatGPT package embeds the guide and records its hashes, so users receive it through the plugin rather than installing a local skill.

Profiles resolve effective light/dark colors, typography, spacing and shapes while preserving explicit project overrides. Managed capability metadata gates typography, screen footers, purchase actions and skeleton loading on supported component versions. Existing projects receive updated guidance on start; their managed components are preserved.

`Skeleton` and `SkeletonBlock` represent genuinely pending asynchronous content. Ready content appears immediately, existing content remains during refresh, and shimmer respects Reduce Motion and app state. Native controls, interaction and accessibility still need device review. The fixtures establish recipe compatibility; they do not establish model adherence or physical-device acceptance.
